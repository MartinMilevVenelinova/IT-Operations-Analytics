# Agent Performance Dashboard

## Objective

This page analyzes how agents perform based on:

- Workload (tickets handled)
- SLA compliance
- Resolution time
- Rework activity

It helps identify overloaded agents and performance risks.

---

## KPIs

- Average Tickets per Agent  
- Team SLA Compliance  
- Median Resolution Time (hours)  
- Overloaded Agents  

---

## Visuals

### Workload vs SLA Compliance (Scatter)

Shows the relationship between workload and SLA performance per agent.

Business question:
Do agents with higher workload show lower SLA compliance?

---

### Tickets by Agent

Displays workload distribution across agents.

Helps identify:
- High workload agents
- Work imbalance

---

### Median Resolution Time by Agent

Shows how long agents take to resolve tickets.

Helps detect:
- Slow resolution
- Possible burnout

---

### Agent Performance Table

Multi-KPI view including:

- Tickets per Agent  
- SLA Compliance Rate  
- Median Resolution Time  
- Rework Rate  

---

## Key Insights

- High workload does not always mean better performance
- Some agents may have high workload and low SLA compliance
- Resolution time can increase with workload
- Overloaded agents may represent operational risk

---

## Notes

- Overloaded agents are defined using a workload threshold
- The threshold can be adjusted depending on the dataset
